## Default Permission

Read the device's motion and compass heading, hear each reading, and hold the screen's rotation

#### This default permission set includes the following:

- `allow-available`
- `allow-start`
- `allow-stop`
- `allow-lock-rotation`
- `allow-unlock-rotation`
- `allow-register-listener`
- `allow-remove-listener`
