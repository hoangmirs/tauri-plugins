## Default Permission

Read prices, buy, finish consumables, and read and restore what this store account owns

#### This default permission set includes the following:

- `allow-register-listener`
- `allow-remove-listener`
- `allow-products`
- `allow-buy`
- `allow-owned`
- `allow-restore`
- `allow-finish`
- `allow-unfinished`
