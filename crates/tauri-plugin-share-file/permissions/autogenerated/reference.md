## Default Permission

Open the phone's share sheet for one file

#### This default permission set includes the following:

- `allow-share`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`share-file:allow-share`

</td>
<td>

Enables the share command without any pre-configured scope.

</td>
</tr>

<tr>
<td>

`share-file:deny-share`

</td>
<td>

Denies the share command without any pre-configured scope.

</td>
</tr>
</table>
