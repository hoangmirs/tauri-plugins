## Default Permission

Show native and rewarded ads, and ask for consent where the law needs it

#### This default permission set includes the following:

- `allow-init`
- `allow-consent`
- `allow-show-native`
- `allow-hide-native`
- `allow-load-rewarded`
- `allow-show-rewarded`
