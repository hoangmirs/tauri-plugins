## Default Permission

Read Remote Config and log Analytics events

#### This default permission set includes the following:

- `allow-mode`
- `allow-set-defaults`
- `allow-fetch`
- `allow-activate`
- `allow-get-all`
- `allow-log-event`
- `allow-set-collection`
